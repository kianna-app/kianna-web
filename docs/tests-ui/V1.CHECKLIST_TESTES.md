- [ ] Tentar salvar com nome vazio mostra erro de validação

- [ ] Após criar, card aparece na listagem sem recarregar a página

- [ ] Toggle no card alterna entre ativo e inativo

- [ ] Recarregar a página mantém o estado salvo

**Excluir serviço**

- [ ] Botão "Excluir" abre confirmação nativa do browser
- [ ] Cancelar a confirmação mantém o serviço

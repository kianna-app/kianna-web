# Boas Práticas de UX para Formulários e Inputs Web

Melhorar a experiência do usuário (UX) em formulários é crucial para aumentar as taxas de conversão e reduzir a frustração do usuário. Abaixo estão as recomendações essenciais:

## 1. Estrutura e Layout

* **Coluna única:** Utilize um layout de coluna única. Formulários em várias colunas costumam confundir o usuário e quebram o fluxo vertical de leitura.
* **Agrupamento lógico:** Agrupe campos relacionados (ex: Dados Pessoais, Endereço, Configurações de Conta) para reduzir a carga cognitiva.
* **Priorize a brevidade:** Solicite apenas as informações estritamente necessárias. Se um campo é opcional, avalie se ele realmente precisa estar ali.

## 2. Rótulos (Labels) e Instruções

* **Labels acima do campo:** Posicione os rótulos acima dos inputs. Isso facilita a leitura rápida e adapta-se melhor ao design responsivo.
* **Não dependa de Placeholders:** O texto de exemplo dentro do campo desaparece quando o usuário digita. Use labels externos para que o contexto nunca seja perdido.
* **Indicação de campos obrigatórios:** Marque claramente os campos obrigatórios (ex: usando um asterisco `*`).

## 3. Inputs e Facilidade de Preenchimento

* **Tipos de Input adequados:** Use `type="email"`, `type="tel"` ou `type="number"` para acionar os teclados corretos em dispositivos móveis.
* **Máscaras de entrada:** Implemente máscaras para campos como CPF, CEP e Telefone para guiar a formatação correta em tempo real.
* **Autocompletar:** Ative o atributo `autocomplete` para que os navegadores ajudem o usuário a preencher dados comuns rapidamente.

## 4. Validação e Feedback

* **Validação Inline:** Não espere o clique no botão "Enviar" para mostrar erros. Valide os campos assim que o usuário terminar de preenchê-los.
* **Mensagens de erro descritivas:** Evite "Campo inválido". Use "O e-mail deve conter um @ e um domínio válido".
* **Feedback positivo:** Mostre uma confirmação visual (como um check verde) quando um campo complexo for preenchido corretamente.

## 5. Botões de Ação (CTA)

* **Texto de ação claro:** Use botões com verbos de ação, como "Criar minha conta" ou "Finalizar cadastro", em vez de apenas "Enviar".
* **Diferenciação visual:** O botão principal deve ter um peso visual maior que botões secundários (como "Voltar" ou "Cancelar").

## 6. Acessibilidade

* **Navegação por teclado:** Garanta que todos os campos sejam acessíveis via tecla `Tab`.
* **Contraste e Foco:** O campo selecionado deve ter um contorno (*focus ring*) bem visível.
